# Вопросы и решение проблем

[Установка](setup.md) · [Команды](commands.md) · [Настройки](settings.md) · [In English](../en/faq.md)

### Чат пишет команды, а ничего не происходит
1. **Моды -> ChatControl -> Основное**: включён ли **Мод включён** и заполнен ли **Канал Twitch** (только имя, без ссылки)?
2. Нужно быть в загруженном сохранении: в главном меню эффекты не работают.
3. Ответы появляются в **чате игры**: нажми Enter в игре, чтобы его открыть.
4. Платным эффектам нужны чипы. Выдай себе `!test chips 1000` или проверь бесплатный: `!hi`.
5. Вредные эффекты могут ждать в очереди: бюджет хаоса, `!pause`, 60 секунд после смерти, существа рядом с ХАБом.
6. Всё равно не работает? Найди строки `LogChatControl` в `%LOCALAPPDATA%\FactoryGame\Saved\Logs\FactoryGame.log`.

### Эффекты срабатывают, хотя в чате никого нет
Это автохаос: после 10 минут тишины ADA запускает случайный эффект. Выключи его в **Автохаос -> Включён**
или увеличь время ожидания.

### Слишком жёстко, как успокоить?
- `!pause` - вредные эффекты ждут, пока не напишешь команду ещё раз. `!panic` - отменяет всё сразу.
- **Сложность 1**, цены выше, кулдауны длиннее, **Бюджет хаоса в минуту** меньше.
- Отключи отдельные эффекты в **Эффекты** или убери их из случайных (**В случайных**).
- Больше **Безопасная зона у ХАБа** - существа не придут на базу.

### После загрузки в сейве остался огромный босс
Титан, который был жив в момент сохранения, вернётся после загрузки - без полоски здоровья и лимита времени. Его можно просто убить.

### Работает ли в мультиплеере?
Пока нет, мод сделан для одиночной игры.

### Команды только на английском?
Эффекты - да: `!boss`, `!fog`, `!gift` и так далее. У основных команд есть русские варианты:
`!чипы`, `!бонус`, `!голос`, `!копилка`, `!топ`, `!статистика`, `!убрать`. Сообщения в чате игры и виджеты - на языке мода.

### YouTube не подключается
- Ключ должен быть от **YouTube Data API v3**, и этот API должен быть включён в том же проекте Google.
- Нужен ID канала `UC...` или ссылка на эфир, а не ник вида `@имя`.
- Эфир должен идти (открытый или по ссылке). Без ссылки мод проверяет раз в 3 минуты.
- Могла закончиться дневная квота (10 000 единиц); она обновляется в полночь по тихоокеанскому времени.
- В логе будет строка `YouTube: HTTP 403 ...` с причиной.

### Виджеты OBS пустые или пишут «widget not found»
- Игра должна быть запущена с загруженным сохранением, виджеты оживают сами.
- В источнике «Браузер» галочка **Локальный файл** снята, адрес начинается с `http://localhost:8787/obs/`.
- Страница «widget not found» показывает все существующие виджеты: нажми на нужный, чтобы увидеть правильный адрес.
- Порт 8787 занят другой программой? Поменяй **Оверлей OBS -> Порт** (применяется сразу) и поправь адреса.

### Могут ли зрители злоупотребить `!test`, `!panic` или `!clear`?
Нет. `!test` работает только у владельца канала: мод проверяет значок владельца Twitch/YouTube, подделать его из чата нельзя.
`!pause`, `!panic` и `!clear` доступны ещё и модераторам.

### Зритель написал на табличке что-то плохое
`!clear ник` уберёт таблички этого зрителя, `!clear` - все. Чем меньше **Длительность** у `!sign`, тем быстрее таблички пропадают сами.

### Чипы сохраняются между стримами?
Да, в `Economy.json`. Они привязаны к аккаунту зрителя, а не к отображаемому нику.

### Что останется в сохранении, если удалить мод?
Питомцы останутся обычными ящеропсами без бирок, подписанные машины потеряют подписи. Больше мод ничего в сейв не пишет.

### Мод куда-то отправляет данные?
Он анонимно читает чат Twitch (`irc.chat.twitch.tv`) и, если указан ключ, чат YouTube через API Google.
Сервер для OBS доступен только с твоего компьютера. Никакой телеметрии, настройки и статистика остаются на диске.
