# Установка и подключение

[Команды](commands.md) · [Настройки](settings.md) · [Вопросы](faq.md) · [In English](../en/setup.md)

## 1. Установка

1. Установи [Satisfactory Mod Manager](https://smm.ficsit.app/).
2. Найди **ChatControl** и нажми установить. SMM сам поставит нужный Satisfactory Mod Loader.
3. Запускай игру из SMM.

Только одиночная игра, мультиплеер пока не поддерживается.

## 2. Подключение Twitch

1. В главном меню открой **Моды -> ChatControl -> Основное**.
2. В поле **Канал Twitch** впиши имя канала: то, что после `twitch.tv/`, например `swittyids`.
3. Загрузи сохранение и напиши в чат Twitch `!chips`. Ответ появится в чате игры (Enter в игре, чтобы его открыть).

Токен, пароль и вход не нужны: мод читает чат как анонимный гость и ничего в него не пишет.

## 3. Подключение YouTube (необязательно)

Чат трансляции YouTube мод читает через бесплатный YouTube Data API. Один раз нужен ключ.

**Как получить ключ (около 5 минут):**
1. Открой [console.cloud.google.com](https://console.cloud.google.com) под любым Google-аккаунтом.
2. **Select a project -> New project**, назови, например, `ChatControl`, **Create**.
3. **APIs & Services -> Library**, найди **YouTube Data API v3**, нажми **Enable**.
4. **APIs & Services -> Credentials -> Create credentials -> API key**. Скопируй ключ (`AIza...`).
5. Желательно: открой ключ, **API restrictions -> Restrict key -> YouTube Data API v3**, сохрани.

**Куда вписать:** **Моды -> ChatControl -> Чат YouTube**
- **API-ключ** - ключ.
- **Канал или трансляция** - ID канала (`UC...`, 24 символа; YouTube -> аватарка -> Настройки -> Расширенные настройки -> Идентификатор канала)
  или ссылка на эфир (`youtube.com/live/...`, `youtube.com/watch?v=...`). Ники вида `@имя` не подходят.

**Как это работает:**
- С ID канала мод ищет начавшийся эфир раз в 3 минуты. Со ссылкой на эфир подключается сразу.
- Во время эфира чат читается раз в 10 секунд (**Проверять чат каждые**).
- Google даёт 10 000 единиц квоты в сутки. При 10 секундах это примерно 5 часов эфира. Поиск эфира стоит дороже,
  поэтому на длинных стримах выгоднее вставлять ссылку на эфир. Квота обновляется в полночь по тихоокеанскому времени (около 10:00 по Москве).
- Super Chat и Super Sticker дают чипы, новые и подаренные спонсорства работают как сабы.

## 4. Виджеты OBS (необязательно)

Пока игра запущена, мод отдаёт три виджета, доступных только с этого компьютера (`127.0.0.1`).

В OBS: **Источники -> + -> Браузер**, сними галочку **Локальный файл**, вставь адрес и задай размер:

| Виджет | Адрес | Размер |
|---|---|---|
| Лента событий: кто что запустил, рейды, сабы | `http://localhost:8787/obs/feed.html` | 560 x 600 |
| Голосование (видно только во время голосования) | `http://localhost:8787/obs/vote.html` | 760 x 330 |
| Копилка и топ зрителей | `http://localhost:8787/obs/pot.html` | 640 x 330 |

- Без игры виджеты пустые и сами оживают, когда игра запустится.
- `?k=1.4` в конце адреса делает виджет крупнее (подойдёт любое число).
- Не включай **Локальный файл**: OBS не даёт локальным страницам читать данные игры.
- Виджеты подписаны на языке мода (русский или английский).

**Свой дизайн:** скопируй файлы из [`Resources/Overlay`](../../Resources/Overlay) в любую папку, поменяй цвета в
`assets/ficsit.css` (или что угодно ещё) и укажи папку в **Моды -> ChatControl -> Оверлей OBS -> Папка виджетов**.
Твои файлы открываются как `http://localhost:8787/obs/<имя файла>`, встроенные продолжают работать.
Данные для своих виджетов: `http://localhost:8787/state` (JSON: события, голосование, копилка, топ, хаос, язык).

## 5. Расскажи зрителям

Зрители не видят чат игры, поэтому им нужно объяснить, как играть. Удобнее всего команда бота, например Nightbot
(`!commands add` в своём чате):

```
!commands add !мод На стриме работает мод ChatControl: чат играет в Satisfactory вместе со мной. Пиши в чат и копи чипы FICSIT, раз в день забирай бонус командой !daily и трать чипы на эффекты: !gift, !rain, !jump, !fog, !ambush, !boss и другие. Полный список - в панелях под стримом.
```

Ответы на `!chips`, `!effects` и похожие команды появляются в чате **игры**: зрители видят их, только если игра на экране стрима.
Поэтому объяснения в самом чате Twitch лучше делать командой бота и панелями под стримом.

Боты по умолчанию игнорируются (`nightbot`, `streamelements`, `streamlabs`, `moobot`, `fossabot`): их сообщения не дают чипов
и ничего не запускают. Своих ботов добавь в **Дополнительно -> Игнорируемые пользователи**.

## 6. Попробуй всё сам

Владелец канала может запускать что угодно бесплатно:

- `!test boss`, `!test fog`, `!test drop` - любой эффект по названию
- `!test chips 1000` - выдать себе чипы
- `!test bits 100`, `!test sub`, `!test gifts 5`, `!test raid 30` - имитация событий
- `!test welcome` - приветствие, которое получают новые зрители
- `!test autochaos` - ADA сработает прямо сейчас

Остановить всё: `!panic`, поставить хаос на паузу: `!pause`.
